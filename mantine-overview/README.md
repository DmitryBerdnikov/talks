# Mantine: презентация

Источник: [материал доклада](../mantine.md). В показе 71 слайд. Их порядок задают подключения в `slides.md`. Визуальный референс — `design/reference.png`.

## Структура

- `slides.md` — общие настройки и явный порядок слайдов через `src`.
- `theme.css` — единый набор цветов и размеров текста, собранный по первым 20 слайдам и общим стилям. Подключается из `style.css`. `--color-primary`, `--color-secondary`, `--color-danger` и остальные `--color-*` задают палитру презентации, `--color-code-*` — подсветку кода, `--font-size-*` — ступени размеров, `--slide-heading-size` — общий размер заголовка. Типографика сведена к 14 размерам: `xs`–`2xl`, три размера заголовков, три размера крупного набора и два относительных размера. Слайды и макеты используют общую палитру; близкие оттенки объединены.
- `slides/title/index.md`, `slides/speaker/index.md` и остальные папки — по одному слайду. Названия папок описывают содержание и не содержат номера: это стабильные имена, которые не меняются при перестановке. В `index.md` находятся frontmatter (`layout`, `class`), текст, Markdown/HTML, локальный `<style>` и заметки докладчика в последнем HTML-комментарии.
- Уникальные изображения и Vue-компоненты лежат в папке своего слайда. Картинки подключаются как `![Схема](./diagram.svg)`, компоненты — явным импортом в `<script setup>` из `./demo.vue`. Для фонов и других путей, которые Vite не может разобрать, используем импорт ресурса либо `public/` с путём `/image.png`.
- `layouts/` — используемые повторяемые макеты и их `<style scoped>`. Для оформления содержимого слотов применяется адресный `:deep()`.
- `setup/shiki.ts` — кастомная тема подсветки `conference-dark` из `setup/code-theme.ts` для кода в обоих режимах. В CSS свойства выделены бирюзовым, значения — красным, селекторы — светлым. Фон блоков кода задаётся через `--color-code-background` в `style.css`.
- `style.css` — общие цвета, типографика и отступы. Глобальные селекторы ограничены `.slidev-layout`, кроме переменных в `:root`.
- `assets/fonts/inter/` — локальные Inter 4.1 в WOFF2 и лицензия SIL OFL 1.1. Regular 400, Medium 500 и Black 900 подключены отдельными файлами для встраивания в PDF; остальные веса и курсив доступны через variable-файлы (100–900). Шрифты подключены в `style.css`, включаются в сборку и работают без внешнего CDN. На слайде об авторе: Black 900 для имени, Regular 400 для подзаголовка, Medium 500 для карточек.
- `global-top.vue` — логотип `logo.svg` и его стили; `slide-top.vue` — автоматический счётчик справа внизу и прогресс-бар вдоль нижнего края. Заполнение равно номеру слайда, делённому на общее число слайдов. У каждого слайда свой экземпляр, поэтому номера и заполнение корректны также в обзоре, режиме докладчика и при экспорте в PDF. В PDF полоса статична на каждой странице.
- `vite.config.ts` — поддержка пути с кириллицей и исправление обработки встроенных стилей кода Slidev 53 в UnoCSS 66.10.

## Разработка

Окружение: Node `24.21.0` и pnpm `12.5.1`, зафиксированные в `package.json`. Для nvm добавлен `.nvmrc`: выполни `nvm install`, затем `nvm use`. Если pnpm ещё не установлен, используй `npm install -g pnpm@12.5.1`.

Установка по lockfile: `pnpm install --frozen-lockfile`. Запуск: `pnpm dev`. Просмотр: http://localhost:3030, режим докладчика: http://localhost:3030/presenter. Правила работы для агентов — в [AGENTS.md](./AGENTS.md).

1. Создай папку `slides/short-title/` с уникальным кратким названием по смыслу в kebab-case, без номера.
2. Добавь `index.md` с одним слайдом. Используй готовый макет; уникальные стили пиши в `<style>`. Slidev автоматически ограничивает их текущим слайдом. Для элементов, создаваемых самим макетом, используй адресный `:deep()`, например `.mantine-packages :deep(header)`. Последним блоком оставляй HTML-комментарий с заметками докладчика.
3. Подключи файл в нужном месте главного `slides.md`: `src: ./slides/short-title/index.md` внутри блока `---`. В первом блоке находятся также общие настройки: отдельный пустой слайд перед подключениями не нужен.
4. Проверь слайд в браузере: текст, заметки, отсутствие обрезания и наложения на логотип или счётчик. Браузер обновляется автоматически.
5. Выполни `pnpm format`, затем `pnpm format:check` и `pnpm build`.

Единственный источник порядка — подключения в `slides.md`; алфавитный порядок папок на него не влияет. Для перестановки перемести целиком блок `---` с нужным `src`. При смене первого слайда поменяй его `src` в блоке общих настроек, сохранив сами настройки. Переименовывать папки и менять относительные ссылки на ресурсы не нужно. Счётчик и прогресс вычисляются Slidev автоматически. Общие компоненты выноси в `components/`, когда они используются несколькими слайдами.

## Форматирование и экспорт

Prettier форматирует проект; `prettier-plugin-slidev` и парсер `slidev` включены только для `slides.md` и `slides/**/index.md`. README остаётся обычным Markdown. Настройки: два пробела, одинарные кавычки, без точек с запятой в JS/TS, ширина 100, сохранение переносов текста.

Если переносы или номера строк в примере кода важны для доклада, используй `<!-- prettier-ignore -->` перед блоком кода и проверь подсветку после форматирования.

Сборка сайта: `pnpm build`. Экспорт PDF: установить `pnpm add -D playwright-chromium`, затем `pnpm export`.

## React-примеры Mantine

Showcase и исполняемые примеры к докладу находятся в отдельном приложении [`examples/react`](./examples/react/README.md), подключённом к общему pnpm workspace. React-зависимости объявлены в его собственном `package.json`; Slidev остаётся в корне. Установка всего проекта: `pnpm install --frozen-lockfile`.

- `pnpm dev:examples` — каталог и демо на http://localhost:4302.
- `pnpm typecheck:examples` — проверка TypeScript примеров.
- `pnpm build:examples` — сборка React-приложения.
- `pnpm build:all` — сборка презентации и React-примеров.

Презентация запускается отдельно: `pnpm dev`. Существующие маршруты showcase сохранены; на главной странице демо есть ссылки на остальные примеры. Если порт 4302 занят старым приложением, можно запустить `pnpm dev:examples --port 4303`.

## Палитра кода

Для кода используется Tokyo Night. Цвета и настройки выделения заданы CSS-токенами `--color-code-*` в `theme.css`; они применяются в предпросмотре, сборке и экспорте. Палитра адаптирована к ролям подсветки презентации, цвет комментариев осветлён для читаемости на проекторе. [Исходная тема Tokyo Night](https://github.com/enkia/tokyo-night-vscode-theme).
