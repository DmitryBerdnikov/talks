## Публикация

1. Из корня репозитория выполни `pnpm build`. Готовый сайт появится в `docs/`.
2. Закоммить изменения вместе с `docs/` и отправь на GitHub.
3. Один раз выбери **Settings → Pages → Source → Deploy from a branch → main → /docs → Save**.

После изменений презентаций повторяй сборку и коммить обновлённую `docs/`.
Исходники и зависимости остаются в папках презентаций; `docs/` содержит только готовый сайт.
Чтобы добавить ссылку на главную, отредактируй корневой `index.html` и пересобери сайт.
